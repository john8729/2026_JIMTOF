# 2026_JIMTOF — Obsidian 노트 열기 중계 페이지 (전용)

JIMTOF 2026 웹 동선 페이지의 "Obsidian 노트" 버튼이 거치는 작은 페이지만 두는 공개 저장소입니다.

- 페이지: `gh-pages` 브랜치 (GitHub Pages)
- 동작: 주소 `#n=<노트 이름>`을 받아, 고정된 볼트·폴더의 노트(`obsidian://open`)만 엽니다.
- 노트 이름은 주소의 `#` 뒤에만 있어 서버로 전송되지 않으며, 외부 요청이나 수집은 없습니다.

> 공개 저장소이므로 참관 자료·메모 등 다른 데이터는 이 저장소에 두지 않습니다.
